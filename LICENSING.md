- Education, research, testing, and evaluation
- Internal use by companies, government bodies, and other organizations
- Internal commercial/production use
- Copying and modifying the source code for those permitted internal uses
- Internal backups and archival copies

## Not allowed without a separate written commercial license

- Reselling or commercially redistributing Data Relay Link

- Building a competing or substitute product using the source code
- OEM, embedding, bundling, or white-labeling Data Relay Link in another product
- Offering Data Relay Link functionality as SaaS, a hosted service, or a managed service
